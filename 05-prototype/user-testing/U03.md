## Tác vụ

| Tác vụ | Đường đi đúng | Tiêu chí hoàn thành | Hoàn thành? | Thời gian | Hành động quan sát, khó khăn | Hỗ trợ đã cung cấp | Phản hồi (ghi rõ nguyên văn hay diễn ý) |
|---|---|---|---|---|---|---|---|
| T1. Tìm từ phiếu | Trang chủ, tab Hồ sơ, phiếu Sinh hóa máu; bài hiện sẵn dưới GLU (K01, K02) | Mở bài glucose máu (K01 hoặc K02), không phải bài nước tiểu. Ghi: thấy bài hiện sẵn hay vẫn đi tìm | | | | | |
